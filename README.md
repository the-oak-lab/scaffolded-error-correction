| File | Description |
|---|---|
| `anonymized_data.csv` | A dataset with all variables needed to reproduce analyses reported in the manuscript and Supplementary Material. One row per participant. |
| `anonymized_tutoring_logs.csv` | Every tutoring interaction in the study, including messages exchanged between participants and the LLM tutor in the Socratic condition. Multiple rows per participant. |
| `codebooks.xlsx` | Variable names and descriptions for both data files. |
| `socratic_analysis.R` | An R script to all analyses reported in the manuscript and Supplementary Material. |
